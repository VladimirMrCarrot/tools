# conection_types

Online: https://tools.mrcarrot13666.me/conection_types/ (folder name kept as is for a stable URL)

Interactive UML relationship map on a forest metaphor, UA/EN, dark/light. One self-contained `index.html`:

- diagram: inheritance, realization, composition, aggregation, association, dependency, with multiplicity and arrowheads at the correct ends
- cheat sheet with notation, test question, forest and software examples, PlantUML line per relationship
- "which relationship?" wizard (four yes/no questions)
- multiplicity and navigability reference
- full PlantUML source of the diagram with copy button
- UML to database mapping (FK placement, ON DELETE behaviour, join table, inheritance strategies) with sample DDL
- self-check quiz, eight situations

Images are WebP, 900 px wide (`cwebp -q 82 -resize 900 0`).
