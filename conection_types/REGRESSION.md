# conection_types: регрес-план

Прогін після будь-яких доробок `index.html` або картинок. Повний прогін ~20 хв, швидкий (розділ «Швидкий прогін») ~5 хв

## Підготовка

1. Локальний сервер з теки `git/tools`: `python3 -m http.server 8765`, сторінка http://localhost:8765/conection_types/ (через `file://` не працює перемикання і localStorage поводиться інакше)
2. Chrome DevTools → Device toolbar, ширини для перевірки: **390** (телефон), **640** і **641** (межа стекованих таблиць і прихованого довідника), **890** і **905** (межа діаграми), **1400** (десктоп)
3. Консоль відкрита, фільтр Errors: за весь прогін жодної помилки
4. Перед прогоном очистити localStorage сайту (Application → Storage → Clear site data): ключі `uml-tree-theme`, `uml-tree-lang`, `uml-tree-domain`, `uml-tree-quiz-best`

## Швидкий прогін (після кожної правки)

Вставити у консоль на ширині 1400 і на 390, обидва рази очікується `ok: true`:

```js
(() => {
  const broken = [...document.images].filter(i => i.getAttribute('src') && i.complete && i.naturalWidth === 0).map(i => i.src);
  const r = {
    noHorizontalScroll: document.documentElement.scrollWidth <= window.innerWidth,
    brokenImages: broken,
    entities: document.querySelectorAll('.entity').length,          // 16: 8 ліс + 8 банк
    relCards: document.querySelectorAll('.rel-card[data-rel]').length, // 6
    quizCards: document.querySelectorAll('.quiz-card').length,      // 8
    tableLabels: document.querySelectorAll('td[data-l-ua]').length, // 65
    navChips: document.querySelectorAll('#section-nav a[data-section]').length, // 7
    decideVisible: !!document.querySelector('#decide ol') && document.getElementById('decide').offsetHeight > 0,
    highlighted: document.querySelectorAll('code[data-syntax] span[class^="syn-"]').length > 100,
    codePanes: document.querySelectorAll('#plantuml .pane-code').length, // 4: puml і mermaid × ліс і банк
    csp: !!document.querySelector('meta[http-equiv="Content-Security-Policy"]'),
    overlayParts: ['ovPair','ovOps','ovMore','ovMoreBody','ovImg'].every(id => document.getElementById(id)),
  };
  r.ok = r.noHorizontalScroll && !broken.length && r.entities === 16 && r.relCards === 6 && r.quizCards === 8 && r.tableLabels === 65 && r.navChips === 7 && r.overlayParts && r.decideVisible && r.highlighted && r.codePanes === 4 && r.csp;
  return r;
})()
```

Далі руками, 1400 px: перемкнути Ліс → Банк, UA → EN, темну → світлу і назад. Нічого не стрибає, тексти міняються всюди (шапка, блоки, підказки, довідник, PlantUML, квіз)

## G. Превʼю PlantUML не відстає від тексту

Картинки превʼю рендеряться локально і лежать поруч (`puml-forest.svg`, `puml-bank.svg`). Рендер: витягти текст із `#puml-src` / `#puml-src-bank` у `.puml` і `plantuml -tsvg -charset UTF-8 <file>.puml`. Щоб не забути їх перегенерувати, у теці лежить `puml-preview.lock`: для кожного домену хеш тексту PlantUML і хеш картинки на момент рендеру. Перевірка рахує обидва хеші заново і порівнює з lock

Запуск з теки `conection_types`:

```bash
python3 check-puml-preview.py            # перевірка, код виходу 1, якщо є розбіжність
python3 check-puml-preview.py --update   # записати поточні хеші в lock після свідомого перерендеру
```

| # | Ситуація | Що робити |
|---|---|---|
| G1 | Обидва домени `ok` | Нічого |
| G2 | `STALE` | Перерендерити картинку цього домену зі свіжого тексту (скіл `diagrams`), потім `python3 check-puml-preview.py --update` |
| G3 | «Картинка змінилась без зміни тексту» | Переконатись, що картинку правили свідомо (інший рендер, тема); якщо так, `--update` |
| G4 | «Перерендерено» | Відкрити превʼю і переконатись, що схема збігається з текстом, потім `--update` |
| G5 | Немає запису в lock | Перший запуск після появи картинок: перевірити превʼю очима і `--update` |

Lock комітити разом із картинками і `index.html` одним комітом

## Де що ламалось раніше (дивитись першими)

- `overflow-x: hidden` на `body` вбиває sticky-панель: перевіряти C1 і C4 після будь-яких правок CSS для телефону
- Клас `static-line` на SVG фарбував усю схему: після правок ліній перевіряти A8
- Дублікат `id="quiz"` стирав заголовок розділу: після правок квізу перевіряти E1 і E4
- Довідник ховався на 641–900: перевіряти D2 і D3 після правок медіазапитів
- Текст PlantUML правлять, а превʼю лишається старим: перевіряти G після будь-якої правки `#puml-src` / `#puml-src-bank`
- Кратність асоціації перекривала блок, стрілка залежності ховалась під Рахунком: перевіряти A7 у Банку
